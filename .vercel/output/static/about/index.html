MESSAGE

1956年の創業以来、私たち藤島製作所は「お客様の課題を技術で解決する」ことを企業使命とし、精密機械加工と金型製造の分野で歩み続けてまいりました。

ものづくりを取り巻く環境は刻々と変化していますが、品質にこだわり、確かな技術を磨き続けるという姿勢は創業時から変わりません。これからも変化に対応しながら、次世代に技術を継承し、社会に貢献できる企業を目指してまいります。

代表取締役 藤島 太郎
